# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [26.1.2.10]

* Tools with Apotheosis' Omnetic affix can mine Adamantite, Aeternium and Aurichalcum ore when any tool in the affix's list can, so an Exalted Omnetic tool now mines Aurichalcum ore (FTBTeam/FTB-Modpack-Issues#13742)
* The Adamantite, Aeternium and Aurichalcum Furnaces and their upgrades show in JEI and the Iron Furnaces creative tab again (FTBTeam/FTB-Modpack-Issues#13767)

## [26.1.2.9]

* The Aurichalcum Blood Orb charges much faster in a NeoVitae Orb Vitae Link or on the altar (fill rate 100 to 320), keeping it ahead of the Divinus Orb

## [26.1.2.8]

* Adamantite, Aeternium and Aurichalcum ME Item Storage Cells accept the same upgrade cards as AE2's own item cells: Fuzzy, Inverter, Equal Distribution and Overflow Destruction (FTBTeam/FTB-Modpack-Issues#13622)

## [26.1.2.7]

* Smithing upgrades now follow one chain: netherite gear upgrades to Adamantite, Adamantite to Aeternium, and Aeternium to Aurichalcum. Aeternium and Aurichalcum gear can no longer be smithed from netherite, and Aurichalcum can no longer be smithed from Adamantite
* Added Brazilian Portuguese (pt_br) translation, thanks to PrincessStellar

## [26.1.2.6]

* Adamantite, Aeternium and Aurichalcum Backpack and Storage Stack Upgrades now fit in upgrade slots and show their stack multiplier tooltip (FTBTeam/FTB-Modpack-Issues#13524)

## [26.1.2.5]

* Asset reorganization

## [26.1.2.4]

* Added optional integrations that use Adamantite, Aeternium and Aurichalcum. Each one only loads when its mod is installed

## [26.1.2.3]

* FTB Armory pickaxes and AIOTs are in `minecraft:cluster_max_harvestables`, so amethyst and geore clusters drop full shards and Fortune applies (FTBTesting/Testing-Issues#4615)
* Adamantite, Aeternium and Aurichalcum rods can be crafted from two ingots, so the scythes are craftable again (FTBTesting/Testing-Issues#4563)
* Jade shows the Adamantite pickaxe as the harvest tool for Aurichalcum ore, a tier above netherite

## [26.1.2.1]

* Initial Release
